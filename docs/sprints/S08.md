# S08 — CLI et API Rust de bout en bout

Lancé le 15 octobre 2026. Statut : implémentation et vérifications locales terminées ; CI multiplateforme à consigner. Revue scientifique indépendante ouverte avant qualification.

## Livrables

- Commandes natives `validate` et `solve`, aide/version et contrôle explicite des arguments.
- Codes 0 succès, 2 usage/options, 3 entrée/préparation, 4 numérique, 5 sortie.
- Chemins natifs, maillage relatif au modèle, sortie relative au répertoire de travail.
- Destinations neuves et parents existants requis, sans écrasement ; manifeste final et aucun succès annoncé après échec.
- Échelles automatiques documentées et options d’échelles/origine, sans modification des paramètres CG du JSON.
- API de fichier indépendante de la CLI et exemple Rust de reproduction.
- Tests natifs et reproduction depuis un répertoire temporaire Unicode différent du répertoire des entrées.
- [Contrat CLI/API](../CLI-API.md), [ADR 0009](../decisions/0009-cli-workflow.md).

## Preuves locales

macOS ARM64, Rust 1.96.0, 15 octobre 2026 : les 120 tests du workspace passent, ainsi que Clippy avec avertissements interdits. Linux possède un test supplémentaire pour les noms non UTF-8, soit 121 tests attendus ; Windows et macOS en ont 120.

La CLI valide le bloc de 8 nœuds et 6 TET4 puis résout ses charges en sept mises à jour CG. Résidu frais 3,1441689529253484×10⁻¹⁵ ; les champs exportés gardent l’erreur analytique maximale de 8,39×10⁻¹⁶, arrondie vers le haut, sous 10⁻¹⁰.

Les fichiers CLI/API, y compris rapport et manifeste, sont identiques dans la reproduction locale. Les chemins avec espaces/accents et un nom de modèle commençant par un tiret passent. Les diagnostics d’entrée donnent le champ concerné. Budget CG insuffisant : code 4, stdout vide et aucune sortie créée. Destination existante : code 5 et données préservées. La validation peut réussir avant un échec de convergence, ce qui est attendu.

Release, documentation Rust avec avertissements interdits, formatage, contrôle de projet, schéma JSON et régénération des trois corpus passent. La CI Windows/macOS/Linux reste à consigner.

## Limites et suite

Les critères de résidu et bilans restent distincts ; les échelles automatiques sont des heuristiques publiées, pas une qualification physique. Pas de reprise après coupure, d’écrasement automatique ou de certification générale des appuis. Les labels de provenance textuels ne prouvent pas les octets source ou une révision de compilation.

S09 prépare la poutre et la convergence de maillage. Le MVP demeure incomplet avant les preuves de comparaison externe et de distribution prévues. Les revues scientifiques indépendantes restent ouvertes.
